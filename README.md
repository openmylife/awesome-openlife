# awesome-openlife

> 🔗 **想「开源自己」？** 从 **[openmylife/openmylife](https://github.com/openmylife/openmylife)** 模板仓开始（`Use this template`）；本仓只负责**收录**。看样板间 👉 **[muamu/openmylife](https://github.com/muamu/openmylife)**。

> 一个「**把自己开源的人**」的收录清单 —— 像 awesome-list，但只收录**人类**。

> **协议适用范围**：本仓文字内容与清单数据适用 [CC BY 4.0](./LICENSE-CONTENT)，代码与脚本适用 [MIT](./LICENSE)；两者冲突时以文件类型判断。

## 这是什么

收录**把自己的笔记、报告与评测、产品、经历公开化**的人。每条记录回答四件事：**是谁 / 开源了什么 / 从什么时候开始 / 在哪能找到 ta**。

与常见 awesome-list 的区别：那些收录工具与教程，这里收录**人**。

## 如何加入

1. 编辑 [`data/people.json`](./data/people.json)，按字段格式追加一条（**只填对方已公开的信息**）；
2. 提一个 PR；
3. 合并后由维护者运行生成脚本，清单自动更新。

> **规则（opt-out · 默认收录）**：**默认收录「已把自己公开」的人**（有公开仓库 / 博客 / 公开 ID 即可）；**只收录本人主动公开的信息**，不收录私人信息、不收录第三方推断；**任何人可随时申请退出**，无需理由。

## 字段说明（`data/people.json`）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 唯一标识（GitHub ID 优先；无 GitHub 者用站点 / 平台 handle），作为主键 |
| `name` | | 展示名，缺省用 `id` |
| `tagline` | | 一句话：我在开源什么 |
| `open_since` | | 开源起始（`YYYY-MM`） |
| `channels` | | 链接：`github` / `blog` / `social` |
| `opens` | | 开源内容标签（自由填写，如 `notes` / `产品` / `日记` / `评测` / `故事`） |
| `category` | | 类目 slug，现为 `ai` / `build` / `writing` / `data` / `knowledge`；加新类目在 `scripts/build-readme.mjs` 的 `CATEGORIES` 里登记一行 |
| `level` | | 知名度分档：`1` 顶级（id 前打 ⭐️，恒排在顶部） / `2` 圈内知名 / `3` 值得关注；缺则按 `3` 处理。顶级段内顺序 = 数据文件中的收录顺序，想调就挪 JSON 里的位置 |
| `lang` | | 排列用的语组：`zh` / `en`；缺则按展示名是否含中日韩字符推断 |
| `consent` | | 收录意愿；**默认按 opt-out 处理（已公开即视为允许）**，显式置 `false` 即退出 |
| `consent_source` | | 若有明确同意：来源（邮件 / PR 勾选 / 私信）；默认收录可留空 |
| `consent_at` | | 若有明确同意：同意日期 |
| `revoke` | | 置 `true` 即从清单移除（**无需说明理由**，也不保留历史记录） |
| `links_back` | | 是否回链维护者（礼貌性，非强制） |

> `category` / `level` / `lang` 三个字段由维护者在合并时判定，**提名时可不填**。

| 档 | 含义 |

| `L2` | 圈内知名：在中文或英文的某个具体社区里有稳定声誉 |
| `L3` | 值得关注：新起或刻意小众，但公开得完整、做法清楚 |

## 退出

任何被收录者提一个 issue 或 PR，把 `revoke` 置为 `true` 即可退出；维护者运行脚本后即从清单移除，**无需说明理由**。

## 生成清单

清单由脚本从 `data/people.json` 生成。**请勿手改 BEGIN/END 之间的内容**：

```bash
node scripts/build-readme.mjs
```

| 参数 | 作用 |
|---|---|
| `--seed=2026-10-25` | 用指定种子排：同一种子 → 同一种排列，便于复盘 |
| `--seed=none` | 每次都真随机 |
| `--shuffle-categories` | 类目之间的顺序也一起打乱（默认按 `CATEGORIES` 固定） |

不传参数时用**当天日期**做种子：同一天跑几次结果一致（不污染 git diff），换一天自动换一批排列。
